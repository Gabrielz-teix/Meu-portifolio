# Jogo - echoes of the forest

- Aqui você encontra o jogo "echoes of the forest" um projeto desenvolvido em grupo no período de 2024/2 na disciplina de Programaçãp Modular.
- A linguagem usda foi python, e a estratégia de estruturação abordada foi a ensinada nas aulas do professor Vinícius Durelli.
- Game: Pasta com os arquivos do projeto, incluindo o próprio jogo que você pode rodar.
- .gitignore: Arquivo de repositório que ignora a pasta de cache criada pelo jogo ao rodar.
