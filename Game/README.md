# Instruções de uso e informações sobre as pastas

- Aqui você encontra:
 . play.py = main do jogo, o arquivo é limpo e chama somente as funções de estágio do jogo
 . pasta src = aqui se encontra os códigos do jogo
 . pasta content = aqui estão as sprites, fontes, sons e mapas do jogo
 . pasta apresentação = nossa documentação explicando sobre cada função e estrutura principal do jogo, além disso, adicionamos 
nosso slide de apresentação e uma pasta com imagens das principais estruturas do jogo.
- Para rodar o jogo é só compilar a main com a linha de código "python play.py".
