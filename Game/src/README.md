# Pasta source(src)

• components - Contém os componentes principais do jogo, como jogador, 
               inimigos e interface. 
• core       - Contém os sistemas centrais, responsáveis por gerenciar aspectos 
               fundamentais do jogo, como física, câmera, entrada de usuário e lógica geral. 
• data       - Armazena dados e configurações do jogo.
• estagios   - Contém os estágios e a lógica de progresso do jogo.
